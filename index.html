one-time Firebase setup — takes 3 minutes

Create a free Firebase project
Go to console.firebase.google.com → Add project → give it any name → Continue (disable Analytics if asked) → Create project.
Add a Realtime Database
In your project, go to Build → Realtime Database → Create database. Choose any region. Select "Start in test mode" → Enable.
Get your web app config
Go to Project Settings (gear icon) → scroll to "Your apps" → click </> (Web) → register app → copy the firebaseConfig object.
Paste your config below
Paste the entire firebaseConfig = { ... } object or just the JSON part.

Config is saved in your browser. Your partner also needs to open this page with their own config saved, or you share the same hosted URL.
